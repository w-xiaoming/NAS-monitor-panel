# 功能介绍

NAS Monitor Panel 是一个功能强大的 NAS 系统监控面板，提供全面的系统状态监控和数据可视化功能。

---

## 功能概览

| 功能模块 | 描述 | 刷新频率 |
|----------|------|----------|
| 系统信息 | 操作系统、架构、运行时间 | 5 秒 |
| CPU 监控 | 使用率、核心数、频率、负载 | 5 秒 |
| 内存监控 | 物理内存、交换空间使用情况 | 5 秒 |
| 温度监控 | CPU 温度传感器数据 | 5 秒 |
| 网络监控 | 接口状态、IP 地址、流量统计 | 5 秒 |
| 存储监控 | 磁盘分区使用情况、IO 统计 | 5 秒 |
| 进程管理 | 进程列表、CPU/内存占用 | 5 秒 |
| 连接状态 | 网络连接信息 | 5 秒 |

---

## 详细功能

### 1. 系统信息

显示服务器的基础系统信息，帮助您快速了解运行环境。

**监控内容**:
- 操作系统类型和版本
- 内核版本
- 系统架构 (x86_64, arm64 等)
- 主机名
- 系统运行时间
- 启动时间

**使用场景**:
- 快速确认服务器环境
- 记录系统运行时间
- 故障排查时提供基础信息

---

### 2. CPU 监控

实时监控 CPU 使用情况，帮助您了解处理器负载。

**监控内容**:
- 整体 CPU 使用率
- 每个核心的使用率
- 物理核心数和逻辑核心数
- CPU 频率（当前、最小、最大）
- CPU 时间分配（用户、系统、空闲）
- 系统负载（1分钟、5分钟、15分钟）

**使用场景**:
- 识别 CPU 瓶颈
- 优化进程调度
- 监控系统负载

---

### 3. 内存监控

实时监控内存使用情况，防止内存不足导致的问题。

**监控内容**:
- 物理内存总量、已用、可用、空闲
- 内存使用率
- 缓存和缓冲区内存
- 交换空间使用情况

**使用场景**:
- 监控内存使用趋势
- 发现内存泄漏
- 优化应用程序内存使用

---

### 4. 温度监控

监控服务器硬件温度，防止过热损坏。

**监控内容**:
- CPU 各核心温度
- 高温阈值
- 临界温度

**使用场景**:
- 监控服务器散热状况
- 预防硬件故障
- 优化机房环境

**注意**: 温度监控需要系统支持，在某些容器环境或虚拟机中可能不可用。

---

### 5. 网络监控

实时监控网络状态和流量。

**监控内容**:
- 网络接口列表
- 每个接口的 IP 地址（IPv4/IPv6）
- 接口状态（启用/禁用）
- 实时上传/下载速度
- 网络 IO 统计（发送/接收字节数、数据包数、错误数）

**使用场景**:
- 监控网络带宽使用
- 识别网络异常
- 优化网络配置

---

### 6. 存储监控

监控磁盘存储使用情况。

**监控内容**:
- 所有磁盘分区信息
- 每个分区的容量、已用、可用空间
- 使用率百分比
- 文件系统类型
- 存储 IO 统计（读写次数、字节数、耗时）

**使用场景**:
- 监控磁盘空间使用
- 预防磁盘空间不足
- 分析存储 IO 性能

---

### 7. 进程管理

查看和管理运行中的进程。

**监控内容**:
- 进程列表（按 CPU 使用率排序）
- 每个进程的 PID、名称
- CPU 和内存占用率
- 进程状态
- 创建时间
- 网络连接状态

**使用场景**:
- 识别高资源消耗进程
- 排查异常进程
- 监控服务运行状态

**API 参数**:
- `limit`: 返回进程数量上限（默认 50，最大 200）

## 界面特性

### 暗色主题

采用现代化的深色 UI 设计，减少视觉疲劳，适合长时间监控。

**主题颜色**:
- 背景色: 深灰色系 (#0f1117, #161b22)
- 强调色: 蓝色 (#58a6ff)
- 成功色: 绿色 (#3fb950)
- 警告色: 黄色 (#d29922)
- 错误色: 红色 (#f85149)

### 响应式设计

完美适配各种设备尺寸：

- **桌面端**: 双栏布局，充分利用屏幕空间
- **平板端**: 自适应布局
- **移动端**: 单栏布局，优化触摸操作

### 导航功能

- 顶部导航栏，快速切换监控模块
- 平滑滚动效果
- 滚动时自动高亮当前模块
- 手动刷新按钮

### 实时更新

- 可配置的自动刷新间隔（默认 5 秒）
- 状态指示器显示当前状态
- 旋转动画表示正在刷新
- 手动刷新按钮

### 数据采集

- 异步 API 设计，支持并发请求
- 最小化系统资源占用

### 前端渲染

- Vue 3 Composition API
- 响应式状态管理 (Pinia)
- 虚拟滚动优化长列表
- CSS 动画优化

- 可配置刷新频率
- WebSocket 支持（可选）
